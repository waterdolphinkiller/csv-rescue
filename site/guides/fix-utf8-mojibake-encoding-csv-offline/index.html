Frequently Asked Questions

Why does Excel show Ã© even when my CSV is valid UTF-8?

Older and Windows versions of Excel assume a CSV without a UTF-8 Byte Order Mark (BOM) is encoded in the local Windows-1252 code page. Adding a UTF-8 BOM (EF BB BF) tells Excel to decode it as UTF-8.

Can CSV Rescue fix characters that already turned into black diamond question marks ()?

If the appears only because the wrong decoder was selected, switching encodings in Encoding Detective fixes it. If 0xEF 0xBF 0xBD is already baked into the raw file bytes, those characters are irrecoverable and CSV Rescue flags that honestly.

Does changing encoding modify my original file on disk?

Never. CSV Rescue keeps your uploaded bytes read-only in memory and only writes a new cleaned file when you click Download.
